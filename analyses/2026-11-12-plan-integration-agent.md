## Corrections métier de l’intégration

Les fichiers React sont publiés sur le serveur. Le web privé et l’EXE les chargent à l’ouverture d’Agent. Fred a ouvert le formulaire EML avec les 11 projets depuis le web privé. La file **À classer** était vide lors de ce contrôle. [Journal de publication](2026-11-13-reprise-integration-agent.md#publication-de-linterface-agent)

- **Rejeter le mail** est ajouté dans la vue **À classer**. L’action retire le message de la file, le conserve dans Agent et Thunderbird et l’exclut des prochains tris. Les tests de permissions et le parcours sur un mail fictif passent, y compris avec un accès limité aux projets. [Interface Mails](../agent/web/src/components/MailWorkspace.tsx) · [Tests de périmètre](../agent/tests/test_project_access.py)
- **Mails rejetés** est disponible dans **Options → Dossier**. Il permet de relire le message et de télécharger son original et ses pièces jointes. Les accès limités aux projets y retrouvent leurs propres rejets encore autorisés. Le rejet confirmé retire le message de la file même si l’actualisation échoue ou renvoie une page périmée. Le service et les ressources publiées ont été vérifiés en HTTPS avec Fred. [Recette et publication](2026-11-13-reprise-integration-agent.md#consultation-des-mails-rejetés)
- **Mails classés** se rafraîchit toutes les 15 secondes quand la vue est ouverte et visible. Un nouveau mail classé devient consultable sans quitter la vue. Le mail en cours de lecture reste sélectionné. Le test couvre un accès limité en lecture seule et l’arrêt du rafraîchissement quand la vue est inactive. [Recette d’actualisation](<D:/Kiara/integration-agent/mail-thunderbird/actualisation-mails-classes.log>)
- **Importer des mails EML** est ajouté dans **Mails → Options**. Un accès en écriture peut choisir un projet autorisé et importer plusieurs fichiers. Le mail original et ses pièces jointes restent consultables dans le projet choisi. La recette HTTP a confirmé le rattachement explicite, la déduplication, le rejet d’un fichier invalide et les refus en lecture seule et hors périmètre. Les tests du composant couvrent aussi le résultat d’un lot avec un fichier invalide. L’import confirme l’enregistrement et confie l’indexation EG2 au traitement durable existant. Les 29 tests serveur ciblés passent. [Indexation après import](<D:/Kiara/integration-agent/mail-thunderbird/import-eml-indexation.log>) [Interface Mails](../agent/web/src/components/MailWorkspace.tsx) · [Recette EML](../agent/tests/test_mail_project_targets.py)
