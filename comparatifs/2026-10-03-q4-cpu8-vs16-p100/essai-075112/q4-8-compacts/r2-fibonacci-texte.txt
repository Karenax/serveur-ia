Voici une implémentation simple et efficace de la fonction `fibonacci(n)` en Python. Cette fonction génère une liste contenant les `n` premiers nombres de la suite de Fibonacci.

```python
def fibonacci(n):
    """
    Retourne une liste contenant les n premiers nombres de Fibonacci.
    """
    if n <= 0:
        return []
    elif n == 1:
        return [0]
    
    fib_sequence = [0, 1]
    for i in range(2, n):
        next_value = fib_sequence[i-1] + fib_sequence[i-2]
        fib_sequence.append(next_value)
        
    return fib_sequence

# Exemple pour n=8
n = 8
result = fibonacci(n)
print(f"Les {n} premiers nombres de Fibonacci sont : {result}")
```

**Sortie pour `n=8` :**
```
Les 8 premiers nombres de Fibonacci sont : [0, 1, 1, 2, 3, 5, 8, 13]
```

### Explication :
1. **Cas de base** : Si `n` est inférieur
