Qwen / Strata : console serveur et Accès serveur Fred 3.2.1

Cette archive contient les sources des deux applications et leurs tests.
Le code applicatif est sous licence MIT. Les dépendances gardent leurs licences,
reproduites dans client-qwen/THIRD-PARTY.txt. Les poids du modèle, le moteur Strata
et leurs licences sont distincts de ces applications.

Le client comporte WireGuard Go et une pile réseau en mémoire. Il n'installe
aucun pilote et ne change ni les interfaces réseau, ni le DNS, ni les routes
Windows. Le serveur utilise le même moteur en mémoire. Le seul port à exposer
dans le pare-feu du serveur et dans la box est UDP 51820 par défaut.

Compilation du client Windows x64 :
1. Installer Go 1.27.1 ou une version compatible avec go.mod.
2. Préparer Python 3.12 avec Tk dans Strata-src/.venv.
3. Depuis la racine de l'archive :
   Strata-src\.venv\Scripts\python.exe -m pip install --target client-qwen\build-tools -r client-qwen\requirements-build.txt
4. Exécuter client-qwen/Build-WireGuard.ps1 puis client-qwen/Build-Client.ps1.
5. La base client-qwen/dist/Accès serveur Fred.exe n'a aucun profil de connexion.
   Générer les EXE personnels depuis Clients & accès dans la console serveur.

Installation des sources serveur sur un autre PC :
- Ce lanceur est adapté au profil Strata avec deux P100. Il ne contient pas le
  moteur, les packs, le tokenizer, le modèle GGUF ni l'environnement Strata.
- Fournir ces composants séparément et installer lanceur/requirements.txt dans
  Strata-src/.venv. Le module serveur de Strata doit être disponible.
- Fournir un fichier lanceur/base-strata.json compatible avec votre moteur :
  exe, args, tokenizer, model_name, host, port et env. Le lanceur conserve les
  options de ce fichier et permet de modifier les chemins dans son interface.
- Les scripts de lancement supposent cette organisation des dossiers ; adapter
  les chemins si vous utilisez une autre installation de Strata.
- Lancer Serveur Qwen.cmd. Configurer l'IP publique ou DNS dans Accès distant, puis
  autoriser le port Windows, créer la redirection de la box et générer les clients.

Tests Windows, depuis lanceur :
  ..\Strata-src\.venv\Scripts\python.exe -m unittest discover -s . -p "test_*.py" -v
Le client et le moteur WireGuard doivent avoir été compilés. Les tests utilisent
un moteur LLM simulé, y compris pour le test chiffré de bout en bout en UDP.
Ils ne chargent pas de poids et ne lancent pas de génération sur votre modèle.

L'archive exclut volontairement toute configuration personnelle : clés privées,
accès API, profils de clients, EXE personnels, adresse publique et poids.
Les clés et les EXE destinataires ne doivent pas être publiés avec les sources.
