Voici la fonction Python demandée, suivie de l'exemple pour `n=8`.

```python
def fibonacci(n):
    """
    Retourne une liste contenant les n premiers nombres de Fibonacci.
    La séquence commence par 0, 1.
    """
    if n <= 0:
        return []
    elif n == 1:
        return [0]
    
    fib_sequence = [0, 1]
    for i in range(2, n):
        next_value = fib_sequence[i-1] + fib_sequence[i-2]
        fib_sequence.append(next_value)
    
    return fib_sequence

# Exemple pour n=8
result = fibonacci(8)
print(f"Les 8 premiers nombres de Fibonacci sont : {result}")
```

**Sortie de l'exemple :**
```
Les 8 premiers nombres de Fibonacci sont : [0, 1, 1, 2, 3, 5, 8, 13]
```
