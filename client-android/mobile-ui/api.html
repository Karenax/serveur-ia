API locale

Connectez une autre application de ce téléphone au serveur Kiara avec une API compatible OpenAI.

Dans l’autre application, choisissez une API compatible OpenAI, puis renseignez cette adresse et cette clé.

Embeddings : modèle google/embeddinggemma-2, 768 dimensions, route /v1/embeddings. Le calcul est effectué sur le serveur.

Gardez Kiara ouvert. Le port et la clé changent quand ce service local redémarre : recopiez-les si nécessaire. Android peut arrêter le service en arrière-plan. L’autre application doit accepter une adresse HTTP locale.

Cette adresse est utilisable sur ce téléphone uniquement. Ne partagez la clé qu’avec les applications auxquelles vous accordez l’accès.
